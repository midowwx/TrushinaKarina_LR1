## Протоколы взаимодействия
1. Протокол CalculatorLogic

Участники: ViewModels и Core.
Назначение: выполнение логики калькулятора.
Интерфейс: статические методы в классе CalculatorLogic.

* Num_Click(TextBox display, object sender) — ввод числа или запятой.
* Op_Click(...) — выбор операции.
* Eq_Click(...) — расчёт результата.
* Clear_Click(...), Back_Click(...), Sign_Click(...) — управление дисплеем.
* Math_Click(...) — математические функции (sqrt, %, sin).
   Формат данных: объекты C#, ссылки на элементы управления WPF.
   Соглашения: прямой вызов методов без интерфейсов; параметры передаются как есть.

2. Протокол HistoryService

Участники: ViewModels и Core.
Назначение: доступ к истории расчётов.
Интерфейс: статическое поле List<string> Entries класса CalculatorHistory.
Формат данных: строка «выражение = результат».
Соглашения: глобальный список для простоты реализации.

3. Протокол Logger

Участники: все модули и Core
Назначение: ведение текстового лог-файла.
Интерфейс: метод void Log(string action);
Формат данных: [YYYY-MM-DD HH:mm:ss] действие.
Соглашения: синхронная запись в файл log.txt.
## Соглашения об именовании и версионировании
 Именование
  * Классы: PascalCase (CalculatorLogic)
  * Методы: PascalCase (Num_Click)
  * Переменные: camelCase (display.Text)
  * Пространства имён: Calculator.Core, Calculator.Views
  * Ветки Git: feature/*, hotfix/*, release/*
  * Коммиты: <тип>: <краткое описание> (например, feat: добавлена новая функция sin).
  * Версионирование: используется SemVer только для внешних зависимостей (packages.config, если применимо). Версия самого приложения указывается в атрибуте [assembly: AssemblyVersion("...")] в файле Properties/AssemblyInfo.cs.
## Заключение
Проект представляет собой классический MVVM-калькулятор. Все взаимодействия между модулями реализованы через прямые вызовы статических методов из слоя ViewModels в слой Core, что упрощает структуру.
