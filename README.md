# Приложение Calculator
Приложение представляет собой калькулятор с двумя режимами работы: обычный и инженерный. Он позволяет выполнять базовые арифметические вычисления и тригонометрические вычисления. Помимо этого в приложении реализована история вычислений и смена увета калькулятора.
## Установка
1. Клонируйте репозиторий: git clone https://github.com/midowwx/TrushinaKarina_LR1.git  cd TrushinaKarina_LR1
2. Откройте файл решения Calculator.scproj в среде Visual Studio 2022.
3. Восстановите пакеты NuGet (включая библиотеку NCalc).
4. Соберите и запустите проект (F5 или Ctrl + F5).
## Использование
Обычный режим: выполнение базовых арифметических операций (сложение, вычитание, умножение, деление, расчет процентов).

Инженерный режим: выполнение сложных математических операций (возведение в степень, извлечение квадратного корня, скобочные выражения).

История операций: просмотр списка ранее выполненных расчетов с возможностью очистки.
 
Выбор темы: представленно 4 темы калькулятора (темная, светлая, серая, неоновая).
## Структура приложения
Core: содержит бизнес-логику программы.

Infrastructure: служебные файлы конфигурации для настройки окружения.

ViewModels: логика представления интерфейса пользователя. 

Views: разметка пользовательского интерфейса на языке XAML.
